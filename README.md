# RSA 加密解密算法实现

使用 **C 语言** 与 **x86 汇编语言（8086 / DOS，MASM）** 分别实现 RSA 非对称加密算法的完整流程：密钥生成、加密与解密。

## 实现原理

RSA 的安全性基于「大整数质因数分解困难」这一数论事实：将两个大素数相乘很容易，但把乘积分解回两个素数却非常困难。

### 1. 密钥生成

- 输入两个素数 `p`、`q`，用费马素性检验（`check_num`）验证其是否为素数；
- 计算模数 `n = p × q` 与欧拉函数 `φ(n) = (p-1) × (q-1)`；
- 选取与 `φ` 互素的公钥指数 `e`：从 `φ` 向下遍历奇数，并用欧几里得算法判断 `gcd(e, φ) = 1`；
- 用扩展欧几里得算法求 `e` 关于 `φ` 的模逆元 `d`。

最终得到公钥 `(e, n)`、私钥 `(d, n)`。

### 2. 加密

```
c = m^e mod n
```

使用快速幂取模（平方-乘）算法实现。

### 3. 解密

```
m = c^d mod n
```

同样使用快速幂取模算法，即可由密文还原明文。

### 涉及的关键算法

- 费马素性检验（`check_num`）
- 欧几里得算法求最大公约数（`Euclid`）
- 扩展欧几里得算法求模逆元（`exgcd` / `extended_euclid`）
- 快速幂取模 / 平方-乘算法（`mod_pow`）
- 32 位 / 64 位大数乘除（`mul32x32`、`divmod32`、`divmod64`）

## 文件说明

| 文件 | 说明 |
| ---- | ---- |
| `z-02.c` | C 语言实现 |
| `z-01.asm` | 8086 汇编实现（MASM 语法，16 位 DOS 环境） |

## 运行环境

- **C 版本**：任意支持 C 的编译器（如 MSVC / GCC）。
- **汇编版本**：DOSBox + MASM 5.0/6.0 + LINK，16 位 DOS 环境。

## 编译与运行

### C 语言

```bash
gcc z-02.c -o rsa
./rsa
```

### 汇编（DOSBox）

```
masm z-01.asm
link z-01.obj
z-01.exe
```

## 使用示例

输入两个素数 `p = 61`、`q = 53`，程序自动计算并显示：

```
n = 3233, fai = 3120
e = 17
d = 2753
```

输入明文 `m = 123`，得到密文 `c = 855`，解密后还原为 `m = 123`。

## 说明

本程序仅用于演示 RSA 的算法原理，运算范围限制在 16 位素数、32 位明文的小整数范围内，不适用于生产环境或大数加密场景。
